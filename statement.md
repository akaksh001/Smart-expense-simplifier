# Problem Statement

## Problem Context
When traveling in a group, living with roommates, or organizing an event, expenses are frequently shared. Keeping track of who paid for what and manually calculating who owes whom can be complex and error-prone. Without a systematic approach, people end up making multiple unnecessary transactions to settle debts.

## Scope
The **Smart Expense Splitter** application is built to handle group expense tracking and debt settlement locally. It allows users to input members, log shared expenses, and view real-time net balances.

## Target Users
* Roommates sharing rent, groceries, and utilities.
* Friends traveling together.
* Event organizers splitting costs among contributors.

## High-Level Features
1. **Add Group Members:** Users can define the participants.
2. **Log Expenses:** Users can record how much was paid, by whom, and for what.
3. **Equitable Splitting:** The system automatically distributes the cost equally among all members.
4. **View Balances:** Users can check their current net balance (positive means they are owed money, negative means they owe money).
5. **Simplify Debts:** A mathematical algorithm computes the most efficient way to settle all debts with the minimum number of transactions.
